# POST Create Resource Request

## Purpose

Test creating a new resource using a POST request with a JSON request body.

## Request

```http
POST https://jsonplaceholder.typicode.com/posts
Content-Type: application/json
```

### Request Body

```json
{
    "title": "Application Support Test",
    "body": "Testing POST request from Postman",
    "userId": 1
}
```

## Result

**Status:** `201 Created`

The API returned the created resource.

Example response:

```json
{
    "title": "Application Support Test",
    "body": "Testing POST request from Postman",
    "userId": 1,
    "id": 101
}
```

The `id` was generated by the server.

---

## Invalid Request Test

The request was then tested with an incorrect data type:

```json
{
    "title": "Application Support Test",
    "body": "Testing POST request",
    "userId": "one"
}
```

The `userId` value was supplied as a string instead of an integer.

### Result

**Status:** `400 Bad Request`

The API rejected the request because the request data did not match the expected API contract.

---

## Corrected Request

The request was corrected:

```json
{
    "title": "Application Support Test",
    "body": "Testing POST request",
    "userId": 1
}
```

### Result

**Status:** `201 Created`

## Key Observation

The request body must conform to the API's expected schema, including required fields and data types.

`Content-Type: application/json` tells the server that the request body is JSON.

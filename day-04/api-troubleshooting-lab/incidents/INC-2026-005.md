# INC-2026-005 -- Unable to Create Post

## Incident Summary

## User Report

User reported that they were unable to create a post and received an invalid request error.

### API Request

**Method:** POST
**Endpoint:** `/post`

### Initial Request Body

```json
{
        "title": "Application Support Test",
        "body": "Testing POST request",
        "userId": "one"
}

```

### Response

Status: `400 Bad Request`


## Investigation

The request reached the API successfully, but the server rejected the request.

The API documentation was checked to verify the expected request schema.

The `userId` field was documented as requiring an integer.

The submitted request contained:
```
"userId": "one"
````

The value was supplied as a string rather than an integer.


### Corrected Request

```json
{
    "title": "Application Support Test",
    "body": "Testing POST request",
    "userId": 1
}

```

The corrected request returned:
`201 Created`


## Root Cause

The `userId` field was supplied using an invalid data type. The API expected an integer but received a string.

## Resolution

Corrected the request body so that `userId` was supplied as an integer.

## Validation

The corrected request returned.
`201 Created`

confirming that the API accepted the request.

## Escalation

Not required


The issue was caught by invalid request data was resolved by correcting the request body.

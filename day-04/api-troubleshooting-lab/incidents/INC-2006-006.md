# INC-2026-006 -- Unable to Retrieve Account Information

## Incident Summary

### User Report

User reported that they were unable to access their account information and received an unauthorized error.

### API Request

**Method:** `GET`
**Endpoint:** `/account`

### Initial Request

```
GET /account
```

### Request headers:
```
Accept: application/json
Authorization: [Missing]
```

### Response

**Status:** `401 Unauthorized`


## Investigation

The request reached the API and returned a `401 Unauthorized` response.

The request headers were inspected and the required `Authorization` header was missing.

The API documentation was checked and confirmed that the `/account` endpoint requires Bearer token authentication.


### Corrected Request

The request was resent with the required authentication header:

```
Authorization: Bearer <token>
```

The actual token was not recorded in the incident documentation.


## Validation

The corrected request returned:
`200 OK`

and successfully returned the account information.


## Root Cause

The required authentication credentials were missing from the original API request.


## Resolution

Added the required Bearer authentication token to the request.

## Evidence

- Original request returned `401 Unauthorized`.
- Authorization header was missing.
- API documentation confirmed Bearer authentication was required.
- Corrected request containing the required authentication header returned `200 OK`.


## Escalation

Not required.

The isseu was caused by missing authentication credentials and was resolved by correcting the request.
